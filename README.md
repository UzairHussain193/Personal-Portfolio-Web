  - Contact Form

## 🚀 Getting Started

### Prerequisites

- [Git](https://git-scm.com/downloads) installed on your system
- A modern web browser
- Code editor (VS Code, Sublime Text, etc.)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/UzairHussain193/Personal-Portfolio-Web.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd Personal-Portfolio-Web
   ```

3. **Open in browser**

   Simply open `index.html` in your preferred browser, or use a local development server:

   ```bash
   # Using Python
   python -m http.server 8000

   # Using Node.js (http-server)
   npx http-server
   ```

4. **Access the website**

   Open your browser and navigate to `http://localhost:8000`

## 🎨 Customization Guide

### 1. **Update Personal Information**
   - Edit `index.html` to update your name, bio, skills, and projects
   - Replace images in `assets/images/` with your own

### 2. **Modify Styling**
   - Edit `assets/css/style.css` to change colors, fonts, and layout
   - CSS custom properties are defined at the top of the file for easy theming

### 3. **Add Projects**
   - Update the portfolio section in `index.html`
   - Add project images to `assets/images/`

### 4. **Configure Contact Form**
   - Get your access key from [Web3Forms](https://web3forms.com/)
   - Update the `access_key` value in the contact form section

### 5. **Update SEO Settings**
   - Modify meta tags in `index.html`
   - Update `sitemap.xml` with your URL structure
   - Customize `robots.txt` as needed
